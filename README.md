## The Drowned Crown

A mobile-friendly 3D fantasy platforming chapter. Wake temporary Echo bridges, recover three star-sigils, evade the roaming wardens, and reach the crown altar.

- **Desktop:** WASD / arrow keys to move, Space to jump, E to activate Echo.
- **Phone/tablet:** drag the left virtual stick; tap **Jump** and **Echo** on the right.
- **Run locally:** serve this folder over HTTP and open `index.html` in a modern browser (Three.js loads from jsDelivr).
